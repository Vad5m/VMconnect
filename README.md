# VMconnect

> **Only for Linux + Android**

This is not a fork of KDEconnect, this is my personal project, 
which does not even look like a project from KDE, 
but I was inspired by it in part, most likely my version is better than KDEconnect, 
but since I am still a beginner, there may be errors.

The project is still in its early stages of development. 
To use it, you need to install the phone version on Android and the PC version. 
Currently, only Linux + Android is supported.
